# Decision log - accepted, rejected, deferred

Every material proposal from the five founding inputs and every subsequent ruling, with a disposition and a reason. "Deferred" means accepted in principle but gated behind a later phase or a trigger condition, not built now. Provenance: the founding proposals, comparative analysis, and synthesis live in the orchestration repository at `projects/software-factory/`; each row names its source in the Source column; console-ruling files land in `../rulings-queue/` (`processed/` once folded in); git history holds the arrival chronicle that used to run on here.
