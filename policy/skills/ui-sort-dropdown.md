# Guide: ui.sort-dropdown

Sort visible option labels case-folded by first name, then last name. Preserve
the exact option membership, values, selected value, and any leading blank or
All sentinel. Locate every named page before editing. Recompute the diff from
the recorded base SHA and run the sorted-permutation postcondition plus the
targeted unit test. `listOrder` may change only when repository evidence proves
it is presentation order rather than routing priority.
